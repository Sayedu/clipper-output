# clipper-output

Public hand-off repo for the daily TikTok auto-poster in [`Sayedu/clipper`](https://github.com/Sayedu/clipper) (private).

Each day's workflow publishes exactly one rendered video here as a GitHub Release asset — a public, direct, no-auth URL that Buffer's API can fetch to post to TikTok. The previous day's release is deleted before the new one is created, so nothing accumulates here.

Nothing else lives in this repo.
